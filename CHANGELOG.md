# Changelog

## 0.3.0 — 2026-11-06

- DarkBooks branding and a redesigned book-inspired interface.
- English by default, with a persistent Russian language switch.
- A cleaner library, book editions, chapter selection and progress display.
- Connection settings separated from the main book-creation flow.
- Original sample story: *The Lantern Keeper*.
- English and Russian getting-started guides.
- Windows portable download with bundled Python and application dependencies.
- Local LM Studio/ComfyUI and compatible cloud API adapters.
- Resumable analysis/rendering and validated FB2 export; image ZIP downloads.
- Public source repository, CI and release workflows.

## 0.2.0 — local prototype

- First browser interface over the existing book illustration engine.
- Isolated projects, sample chapters, pause/resume and model connections.
- Face replacement kept outside the browser pipeline after local experiments.
