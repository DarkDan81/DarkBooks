# DarkBooks 0.3.0

An early, book-inspired app for turning FB2 books into illustrated editions.

## Download and start

Download **DarkBooks-Windows-x64.zip**, extract the whole folder, and open **Start.cmd**.
Python and the app's dependencies are included. Model weights and servers are separate.

- English by default; switch to Russian in the sidebar.
- Local LM Studio + ComfyUI or compatible cloud APIs.
- Book upload, original sample story, chapter selection, atmosphere and style.
- A separate sample chapter before a full edition.
- Pause/resume, gallery, illustrations ZIP, and validated FB2 export.

[Connection guide](https://github.com/DarkDan81/DarkBooks/blob/main/docs/GETTING_STARTED.md)
· [Русская инструкция](https://github.com/DarkDan81/DarkBooks/blob/main/docs/GETTING_STARTED.ru.md)

This release is experimental. Generated faces/details may vary, and automatic face
replacement is not enabled in the app. Input/output is FB2; cloud API compatibility
depends on your provider and model. Start with a sample chapter.

The archive includes no private books, model weights or API keys. It includes only
the original DarkBooks sample story. Keep your populated `data` folder private.
